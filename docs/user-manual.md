# Excel Utility User Manual

## Filtering

The filtering feature allows you to filter a data sheet using values from another file. You can build complex, nested AND/OR logic to define your filter criteria.

### Group Previews

Each group in the Filter Logic Builder has a "Preview" button and a match count badge.

- **Preview Button**: Click this button to open a new tab in the Unified Data View area that shows only the rows matching the rules within that specific group.
- **Match Count Badge**: This badge shows the number of rows that match the filter logic for that group. The count updates automatically as you add, remove, or change rules.

### Multi-Sheet Export

The "Download Filtered Results" button now exports a single Excel file with multiple sheets:

- **Unified_Result**: The first sheet contains the combined result of all filters.
- **Group Sheets**: Subsequent sheets contain the results for each individual filter group. The sheet names are based on the group names.
